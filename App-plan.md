# 2 Smooth Workstation App Plan

## First usable version

- Two audio decks
- Load local audio files
- Play and pause each deck
- Per-deck volume, master volume, and crossfader
- Portrait layout with one deck emphasized; landscape layout with both decks
- TalkBack-friendly labels and accessible controls

## Planned audio controls

- Vocals, drums, bass, and other stems on each deck
- Mute, solo, and volume controls for each stem
- Bass, mid, and treble EQ for each deck
- Master gain and volume
- Beat matching and tempo control
- Waveforms and single-touch scratching
- Headphone cue for each deck
- Session recording and save

## Accessibility and settings

- TalkBack voice feedback toggle
- Haptic feedback toggle
- Single-Touch DJ Mode (on by default)
- Multi-Stem Solo (off by default)
- Color customization
- Answer-only-in-headphones option
- Reset one deck, both decks, or all settings
- Clear songs or clear all, with confirmation

## Later work

- Stem separation
- Voice commands for loading songs
- Bluetooth and wired cue routing
- Three-two-one start countdown
- Splash screen
